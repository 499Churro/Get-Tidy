# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

A mobile app for college roommates to manage shared household chores. Covers house creation, chore assignment and rotation, push notifications, and a gamification layer. See the PRD for full phase breakdown.

## Status

Pre-scaffolding. Stack and architecture are being determined during brainstorming. Update this file once the stack is chosen and the project is scaffolded.

## Design Principles (from PRD)

- **Punch the chore, not the person.** Surface data, not verdicts. Never name who broke a streak.
- **Frictionless by default.** Logging a chore must take 2 taps or fewer.
- **Playful tone.** Notifications and empty states feel like a friend, not a system.
- **The app is the scoreboard, not the referee.**
