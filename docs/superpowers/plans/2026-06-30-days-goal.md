# Days-Based House Goal Implementation Plan

**Goal:** Replace percentage-based momentum goal with a "days active together" goal — every house member must complete at least one chore on a day for it to count. Progress bar lives on both the home tab (with star animation) and house tab.

**Architecture:** DB migration → Edge Function → types/hooks → House tab UI → Home tab bar + animation. Each checkpoint is independent once the prior one ships.

**Rules:**
- A day is "active" if every house member who had at least one active assigned chore completed at least one of their chores that day
- Members with no assigned active chores on a given day are neutral (excluded from requirement)
- If no members had chores on a given day → skip it (neutral house day)
- `active_days` is the count of such days from month start to today

```ts
// ── 9b. Count active days (every member with chores completed ≥1) ─────────
// Build map: date → Set of user_ids who completed something
const completionsByDate = new Map<string, Set<string>>()
for (const comp of completions ?? []) {
  if (!completionsByDate.has(comp.for_date)) completionsByDate.set(comp.for_date, new Set())
  completionsByDate.get(comp.for_date)!.add(comp.completed_by)
}

let activeDays = 0
const allDays = daysInRange(monthStart, evalEnd)
for (const day of allDays) {
  const dow = new Date(day + 'T00:00:00Z').getUTCDay()
  // Which house members had at least one active assigned chore on this day?
  const membersWithChores = new Set<string>()
  for (const chore of chores) {
    if (chore.assigned_to && memberIds.has(chore.assigned_to) && isChoreActiveOnDate(chore, day, dow)) {
      membersWithChores.add(chore.assigned_to)
    }
  }
  if (membersWithChores.size === 0) continue  // neutral day
  const dayCompletions = completionsByDate.get(day) ?? new Set()
  const allDone = [...membersWithChores].every(uid => dayCompletions.has(uid))
  if (allDone) activeDays++
}
```

```ts
function getRecapCopy(m: HouseMomentum): string {
  const remaining = m.target_days - m.active_days
  if (m.active_days >= m.target_days) {
    return m.reward_text ? `${m.reward_text} unlocked. Well done.` : 'Goal reached. Well done.'
  }
  if (remaining <= 3) {
    return m.reward_text
      ? `So close — ${remaining} more day${remaining === 1 ? '' : 's'} to ${m.reward_text}.`
      : `${remaining} more day${remaining === 1 ? '' : 's'} to go.`
  }
  return m.reward_text
    ? `${m.active_days} days in. ${m.reward_text} is in reach.`
    : `${m.active_days} days in this month.`
}
```

Where `progressAnim` is an `Animated.Value` tracking fill width as a percentage string (use `interpolate` or just animate to the numeric percent then use `widthPercent`).

Use a `useRef` for the animated value, update it with `Animated.timing` when `momentum.active_days` changes:
```tsx
const progressAnim = useRef(new Animated.Value(0)).current

useEffect(() => {
  if (!momentum) return
  const pct = Math.min(100, Math.round((momentum.active_days / momentum.target_days) * 100))
  Animated.timing(progressAnim, {
    toValue: pct,
    duration: 600,
    useNativeDriver: false,  // width animation requires false
  }).start()
}, [momentum?.active_days])
```

Render as:

### Star animation

When `markDone` succeeds, trigger a star (✦) that flies from the chore area up to the progress strip.

Add alongside existing `pillOpacity`/`pillY` refs:
```tsx
const starOpacity = useRef(new Animated.Value(0)).current
const starY = useRef(new Animated.Value(0)).current
const starScale = useRef(new Animated.Value(1)).current
const [showStar, setShowStar] = useState(false)

function triggerStarAnimation() {
  setShowStar(true)
  starOpacity.setValue(1)
  starY.setValue(0)
  starScale.setValue(1.2)
  Animated.parallel([
    Animated.timing(starY, { toValue: -300, duration: 700, useNativeDriver: true }),
    Animated.timing(starScale, { toValue: 0.3, duration: 700, useNativeDriver: true }),
    Animated.sequence([
      Animated.delay(500),
      Animated.timing(starOpacity, { toValue: 0, duration: 200, useNativeDriver: true }),
    ]),
  ]).start(() => setShowStar(false))
}
```

Call `triggerStarAnimation()` alongside `showPointPill()` in `handleToggle`:
```tsx
showPointPill(isOverdue ? '+15' : '+10')
triggerStarAnimation()
```
