How should roles work?

This shapes who can create rewards, set point values, and manage the house — for both roommates and families.

A

Everyone equal

Any member can create rewards, edit chores, manage the store. No hierarchy. Works well for roommates who trust each other.

Pros

  • No friction to get started
  • Feels democratic

Cons

  • Anyone can create "do my homework" as a reward
  • Doesn't work for families — kids can't manage themselves
B

One admin per house Recommended

Whoever creates the house is the Admin. Members earn and spend points. Admin controls the store, chore assignments, and point values. For families: parent = admin, kids = members.

Pros

  • Clean separation — works for both families and roommates
  • One person "owns" the rules
  • Kids can't cheat the store

Cons

  • Roommates may feel one person has too much power
C

Flexible roles — any member can be promoted

Admin can promote any member to Admin too. Multiple admins allowed. For roommates: everyone gets promoted. For families: only parents are admins.

Pros

  • Most flexible
  • Roommates feel equal; families stay hierarchical

Cons

  • More complexity to build and explain
  • Easy to accidentally give kids admin
