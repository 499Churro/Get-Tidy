How do kids join?

Young kids don't have email addresses. How should they get into the app?

A

Standard sign-up — email required

Kids use the same flow as everyone else. Parent sets up an email for them (e.g., kidname@gmail.com) and they log in with that.

Flow: Parent creates email → kid downloads app → signs up → joins with house code

Pros

  • Zero new code — works today
  • Kids learn to manage their own account

Cons

  • Friction for young kids (6–10)
  • Parent has to manage another email
B

Parent-created child accounts Recommended

Admin creates a child account from inside the app — just a name and a 4-digit PIN. Child uses the PIN to log in on their device. No email needed.

Parent flow: House tab → Add member → "Create child account" → enter name + PIN

Kid flow: Open app → "I'm a kid" → enter house code + PIN → in

Pros

  • Works for any age — even 6 year olds
  • Parent stays in full control
  • Dead simple for kids

Cons

  • More work to build (new auth path)
  • PIN-only accounts have less security
C

Same house code join — parent marks as child after

Kid signs up with email (or parent's email), joins with house code, then parent marks their account as "child role" inside the app.

Flow: Kid joins normally → parent opens House tab → taps member → sets role to "Child"

Pros

  • Minimal new auth code
  • Role assignment already fits the flexible-roles model

Cons

  • Still requires an email for the kid
  • Role change is easy to forget
