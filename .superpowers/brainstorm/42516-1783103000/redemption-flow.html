How does spending points work?

When a member wants to redeem a reward from the store, what happens?

A

Self-service — instant claim

Member taps a reward, points are deducted immediately, reward is marked claimed. No admin involved.

Flow: Browse store → tap reward → points deducted → ✅ Claimed

Best for

  • Roommates ("skip dishes night" doesn't need approval)

Problem

  • Kids can claim "stay up late" at 2am without parent knowing
B

Always requires admin approval

Member requests a reward. Admin gets a push notification and approves or denies it. Points only deduct on approval.

Flow: Browse store → tap reward → request sent → admin approves → ✅ Claimed

Best for

  • Families — parent stays in control

Problem

  • Overkill for roommates — nobody wants to ask permission for a fun reward
C

Admin chooses per reward Recommended

When creating a reward, admin marks it as Instant or Needs approval. Both modes coexist in the same store.

Example:
🟢 Instant — "Pick the movie tonight" (50 pts)
🔵 Needs approval — "Stay up 1 hour late" (100 pts)

Pros

  • Works for both families and roommates
  • Admin decides what needs oversight
  • Most natural UX for both contexts

Cons

  • Slightly more to configure when creating a reward
