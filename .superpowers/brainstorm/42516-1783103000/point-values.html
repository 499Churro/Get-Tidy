How are chore points set?

When someone completes a chore, how does the app decide how many points to award?

A

Fixed system

Every chore is worth the same amount. Simple, no configuration needed.

✅ On time → 10 pts ⚠️ Overdue → 15 pts

Pros

  • Zero setup — just do chores, earn points
  • Fair, no disputes

Cons

  • Scrubbing toilets = doing dishes = unfair
  • Admin can't reward harder chores more
B

Admin sets points per chore Recommended

When creating or editing a chore, admin sets the point value. Full control, rewards effort fairly.

🧹 Sweep floors10 pts
🚽 Clean bathroom25 pts
🪟 Wash windows40 pts

Pros

  • Harder chores = more points = fair
  • Admin can incentivize least-liked chores
  • Works perfectly for family context

Cons

  • Admin needs to think about point values when creating chores
C

Difficulty tiers

Admin picks Easy / Medium / Hard when creating a chore. Points are preset per tier.

🟢 Easy → 10 pts 🟡 Medium → 20 pts 🔴 Hard → 40 pts

Pros

  • Quick to set up, no math needed
  • Clear and understandable for kids

Cons

  • Less precise than custom values
  • Tier labels can feel subjective
