How do roommates join a house?

This shapes the entire onboarding experience — how does someone get from "just downloaded the app" to "in my house with my roommates"?

A

Invite Link / QR Code

One roommate creates the house, shares a link or QR code. Others tap it to join.

Frictionless. Works in group chats. No email required. Most consumer apps do this.

B

House Code

House gets a short code (e.g. TIDY-4821). Roommates type it in to join.

Works in any context — text, word of mouth, whiteboard. No link needed.

C

Both

Invite link for easy sharing, house code as a fallback.

Best UX, slightly more to build. Recommended for a social app.
