Who can create and assign chores?

This determines how much authority/hierarchy exists in a house. College roommates tend to resist anything that feels like a boss.

A

Anyone in the house

Any member can create chores and assign them to any roommate (or leave unassigned).

Flat, democratic. Matches how roommates actually work. No one feels like a "chore manager."

B

House creator only

Only the person who created the house can add/assign chores. Others just mark them done.

Cleaner to build, but creates a power dynamic that could breed resentment.

C

Anyone — but only edit/delete your own

Any member can create chores. You can only edit or delete chores you created.

Balanced ownership. Prevents one person from wiping everyone else's chores.
